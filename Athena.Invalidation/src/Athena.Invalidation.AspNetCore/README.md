# Athena.Invalidation.AspNetCore

ASP.NET Core integration for the universal cache invalidation engine.

## Installation

```bash
dotnet add package Athena.Invalidation.AspNetCore
```

## Features

- Dependency injection extensions
- Health checks integration
- ASP.NET Core hosting support
- Configuration binding

## Usage

```csharp
services.AddInvalidation();
```

For a complete solution with all dependencies, use the meta-package:

```bash
dotnet add package Athena.Invalidation
```
