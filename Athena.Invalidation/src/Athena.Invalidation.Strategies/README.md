# Athena.Invalidation.Strategies

Built-in invalidation strategies for the universal cache invalidation engine.

## Installation

```bash
dotnet add package Athena.Invalidation.Strategies
```

## Included Strategies

- **BasicInvalidationStrategy** - Simple table/pattern-based invalidation
- **HierarchicalInvalidationStrategy** - Complex dependency management

## Usage

For a complete solution with all dependencies, use the meta-package:

```bash
dotnet add package Athena.Invalidation
```
