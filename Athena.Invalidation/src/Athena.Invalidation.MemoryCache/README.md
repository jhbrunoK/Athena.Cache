# Athena.Invalidation.MemoryCache

Memory cache integration for Athena cache invalidation engine.

## Installation

```bash
dotnet add package Athena.Invalidation.MemoryCache
```

## Features

- IMemoryCache integration
- Local in-memory cache invalidation
- High performance for single-server scenarios
- Health checks support

## Usage

For a complete solution with all dependencies, use the meta-package:

```bash
dotnet add package Athena.Invalidation
```
