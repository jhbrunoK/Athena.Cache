# Athena.Invalidation.Hierarchical

Hierarchical cache invalidation system for complex data relationships and nested cache dependencies.

## Installation

```bash
dotnet add package Athena.Invalidation.Hierarchical
```

## Features

- Hierarchical cache key management
- Parent-child cache relationships
- Cascade invalidation support
- Tree-structured cache dependencies
- Advanced hierarchy traversal

## Usage

```csharp
services.AddHierarchicalInvalidation();
```

For a complete solution with all dependencies, use the meta-package:

```bash
dotnet add package Athena.Invalidation.Advanced
```
