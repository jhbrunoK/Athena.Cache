# Athena.Invalidation.Redis

Redis integration for Athena cache invalidation engine.

## Installation

```bash
dotnet add package Athena.Invalidation.Redis
```

## Features

- StackExchange.Redis integration
- Distributed cache invalidation
- Redis connection pooling and resilience
- Health checks support

## Usage

For a complete Redis solution with hybrid caching, use the meta-package:

```bash
dotnet add package Athena.Invalidation.Redis
```
