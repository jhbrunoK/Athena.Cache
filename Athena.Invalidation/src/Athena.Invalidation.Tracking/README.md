# Athena.Invalidation.Tracking

Advanced cache key pattern matching and tracking system for Athena cache invalidation engine.

## Installation

```bash
dotnet add package Athena.Invalidation.Tracking
```

## Features

- Advanced cache key tracking
- Pattern matching and analysis
- Key relationship management
- Performance analytics

## Usage

For a complete solution with all dependencies, use the meta-package:

```bash
dotnet add package Athena.Invalidation
```
