# Athena.Invalidation.Engine

Core implementation of the universal cache invalidation engine.

## Installation

```bash
dotnet add package Athena.Invalidation.Engine
```

## Features

- Main invalidation engine implementation
- CQRS pattern support (commands, events, read models)
- Strategy orchestration
- Provider coordination
- Performance optimization and resilience patterns

## Usage

For a complete solution with all dependencies, use the meta-package:

```bash
dotnet add package Athena.Invalidation
```
